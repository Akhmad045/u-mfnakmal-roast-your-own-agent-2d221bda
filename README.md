## What it does

`main.py` writes one original, single-line roast of my own AI agent to `/output/entry.txt` — funny and playful, never hateful. The joke targets my agent's habit of turning every small task into a plan, a helper subagent, and a proud report about the plan.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Standard library only, no network.
